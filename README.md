I build full-stack apps, mostly with **Next.js, Node.js, PostgreSQL and Prisma**, and I care most about the backend: APIs, data models, and making things not fall over. I also ship mobile apps with React Native.

Right now I'm digging into **how Bitcoin actually works** (consensus, the UTXO model, transaction validation), building with **Web3**, and experimenting with **AI agents** that use tools and run real workflows.

- 🥉 2nd runner-up at the **Parul University AI-ML Hackathon**
- 🧩 **350+** problems solved on LeetCode, GeeksforGeeks and Codeforces
- 🤝 Up for collaborating on open source, Web3, agent projects, or a hackathon team
